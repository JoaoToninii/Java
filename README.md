# Repositorio de Estudos e Projetos Java

Repositorio destinado ao armazenamento e versionamento de projetos, desafios e estudos desenvolvidos em Java e ecossistema Spring.

## Projetos Disponiveis

### 1. [ProjetoDIO](./ProjetoDIO/) - Voice Budget AI
- **Descricao**: API inteligente de orcamento e gestao financeira com Spring Boot e Spring AI.
- **Destaques**:
  - Processamento e transcricao de audio por voz via **Whisper (STT)**.
  - Execucao inteligente de transacoes financeiras e consultas usando **OpenAI Function Calling (@Tool)**.
  - Resposta sintetizada por voz via **Text-to-Speech (TTS)**.
  - Painel web interativo para gravacao de audio em tempo real e visualizacao de transacoes.
  - Banco de dados em memoria **H2** com console interativo.
- **Como executar**: Acesse a pasta ProjetoDIO e siga as instrucoes do [README](./ProjetoDIO/README.md).
